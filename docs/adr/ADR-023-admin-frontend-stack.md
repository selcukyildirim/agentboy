# ADR-023: Admin Frontend Stack

## Status

Proposed

## Context

Internal admin panel for product operations.

## Decision

**React** + **Tailwind CSS** + **shadcn/ui** (to be confirmed).

## Alternatives

- **Vue**: Good but less ecosystem
- **Svelte**: Fast but smaller ecosystem

## Consequences

- Rapid development
- Component library
- TypeScript support
- Good for internal tools
